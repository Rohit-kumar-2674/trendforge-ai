# Community code of conduct

Treat contributors and users respectfully. Discuss evidence, tradeoffs and code without personal attacks. Welcome beginner questions and provide reproducible examples. Do not harass, threaten, discriminate, publish private information, or pressure people to disclose credentials.

Maintain honest claims about data and model performance. Do not advertise fabricated predictions, manipulate evaluations, erase misses or conceal provider restrictions. Disagreements about methods should be resolved through transparent assumptions and reproducible tests.

Maintainers may remove harmful content, request changes, restrict participation or reject contributions that violate these principles. Report conduct concerns privately through available repository-maintainer contact mechanisms. Apply these standards to repository issues, reviews, discussions and related community spaces.
