# Changelog

## 0.1.0 — Initial research MVP

- Working Python API/CLI with SQLite migrations and append-only forecast/outcome storage.
- Deterministic multi-domain demo plus mock-tested finance, YouTube and GitHub adapters.
- Causal smoothing/derivatives, configurable trend scoring, lifecycle and anomaly detection.
- Historical analogues, conservative probabilistic baseline, audit replay and outcome evaluation.
- Responsive React dashboard with search, radar, heatmap, comparison, evidence, watchlist, reports and research lab.
- Walk-forward metrics, chronological calibration utilities and offline ML comparisons.
- Provider plugin entry points, documentation, CI, daily state restoration, weekly research evaluation and Docker configuration.
- Explicit unsupported-provider labels, synthetic provenance and documented deployment/validation limits.
